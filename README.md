# Neuvi – Datenschutzerklärung / Privacy Policy

Official Privacy Policy for the **Neuvi** mobile application (developed by **DiA42 – Gesellschaft für digitale Medizinprodukte mbH**), compliant with the General Data Protection Regulation (GDPR / DSGVO), Apple HealthKit, and Google Health Connect requirements.

## 🌐 Live URLs

* **Official Domain:** [https://dia42.de/neuvi/app/dataprivacy.html](https://dia42.de/neuvi/app/dataprivacy.html)
* **Preview Deployment:** [https://neuvi-privacy-policy.vercel.app](https://neuvi-privacy-policy.vercel.app)

## 📋 Features

* **Bilingual Support:** Full German (*Deutsch*) and English versions with an instant language switcher.
* **Self-Contained:** Zero external CSS/JS dependencies for 100% reliability, instant load times, and easy offline archiving.
* **Regulatory Compliance:**
  * GDPR / DSGVO (Articles 6, 9, 12, 13, 14, 15–21, 28, 32, 45, 46).
  * Apple HealthKit data usage policies.
  * Google Health Connect Limited Use policy.
* **Account Deletion Routing:** Built-in anchor link (`#delete-account`) compliant with Google Play and Apple App Store account deletion requirements.

## 📁 Files

* `dataprivacy.html` – The standalone privacy policy file (for hosting at `dia42.de/neuvi/app/dataprivacy.html`).
* `index.html` – The default web root entry point.
